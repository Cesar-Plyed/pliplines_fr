# Pliplines FR

Una aplicación frontend moderna construida con **React**, **TypeScript** y **Vite**.

## Descripción

Pliplines FR es una aplicación web frontend que utiliza las mejores prácticas modernas de desarrollo. El proyecto está optimizado para rendimiento, mantenibilidad y experiencia del desarrollador.

## Stack Tecnológico

- **React 18.2** - Librería de interfaz de usuario
- **TypeScript 5.7** - Tipado estático para JavaScript
- **Vite 6.1** - Herramienta de construcción rápida
- **Tailwind CSS 4.0** - Framework CSS utilidad
- **Material-UI (MUI) 5.15** - Componentes de interfaz de usuario
- **React Router 6.22** - Enrutamiento de aplicación
- **TanStack React Query 5.69** - Manejo de estado de servidor
- **Axios 1.7** - Cliente HTTP
- **Emotion** - Librería de CSS-in-JS

## Características Principales

- ✅ Desarrollo rápido con HMR (Hot Module Replacement)
- ✅ Tipado completo con TypeScript
- ✅ Componentes de Material-UI
- ✅ Enrutamiento con React Router
- ✅ Manejo de peticiones HTTP con Axios
- ✅ Gestión de estado del servidor con React Query
- ✅ Virtualizacion de listas con react-virtualized
- ✅ Animaciones con Motion
- ✅ Linting automático con ESLint
- ✅ Soporte para SCSS con Sass Embedded

## Inicio Rápido

### Requisitos Previos

- Node.js (v16 o superior)
- npm o yarn

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/Cesar-Plyed/pliplines_fr.git
cd pliplines_fr

# Instalar dependencias
npm install
```

### Comandos Disponibles

```bash
# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build

# Ejecutar linter
npm run lint

# Vista previa de la construcción de producción
npm run preview
```

## Configuración de Desarrollo

### TypeScript

El proyecto usa configuración completa de TypeScript para máxima seguridad de tipos. Consulta `tsconfig.json` para ver todas las opciones configuradas.

### ESLint

Se ejecuta linting automático para mantener la calidad del código:

```bash
npm run lint
```

### Vite

Vite proporciona:
- HMR instantáneo
- Pre-bundling de dependencias
- Optimización automática de activos

- **Material-UI** - Componentes estilizados
- **Emotion** - CSS-in-JS
- **SCSS/Sass** - Preprocesador CSS
